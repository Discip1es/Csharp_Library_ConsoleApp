# LibraryApp

Консольное приложение на C# (.NET 8) — простая библиотечная система с выдачей и возвратом книг. Демонстрирует слоистую архитектуру, DI, асинхронность, персистентность в JSON и покрытие юнит-тестами.

## Возможности

- 📚 **Каталог книг** — добавление, поиск по названию/автору, список
- 👤 **Читатели** — регистрация, список
- 🔄 **Выдача и возврат** — с автоматическим учётом свободных копий
- 📊 **Активные выдачи** — просмотр того, что сейчас на руках
- 💾 **Персистентность** — данные сохраняются в JSON между запусками
- ⚡ **Async/await + CancellationToken** — прерывание по `Ctrl+C`
- 🧪 **Тесты** — xUnit, unit + интеграционные
- 🪵 **Логирование** — `ILogger<T>` через `Microsoft.Extensions.Hosting`
- 🧩 **Тестируемый UI** — через абстракцию `IConsole`
